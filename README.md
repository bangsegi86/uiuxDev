# uiuxDev — WYSIWYG UI/UX Builder

웹 기반 위지윅(WYSIWYG) UI/UX 빌더입니다. **PC·모바일 화면**을 컴포넌트로 구성하고,
사용자가 직접 컴포넌트를 만들어 재사용하며, 프로젝트/폴더/화면 단위로 관리합니다.
**서버 + 클라이언트** 웹 애플리케이션이며, 저장은 **로컬 파일(기본)** 또는
**데이터베이스(PostgreSQL / Oracle)** 중에서 선택할 수 있습니다.

## 주요 기능

- **3분할 편집기**: 왼쪽(컴포넌트·탐색기·템플릿) · 가운데(디자인 캔버스) · 오른쪽(속성)
- **화면 = 1파일**: 화면 한 장이 각각의 파일로 저장/불러오기
- **보드(흐름도) = 별도 파일**: 프로젝트의 화면들을 **수동으로 올려** 배치하고
  **연결선/화살표**로 화면 전환 흐름을 표현. 보드에서 화면을 더블클릭하면 편집 탭으로 열림
- **IDE식 탭**: 화면·보드를 여러 개 동시에 열어 탭으로 전환
- **화면 크기 지정**: 화면 추가 시 PC/모바일 선택 + 가로·세로 크기 지정, 편집 중에도 변경 가능
- **컨텍스트 팔레트**: 화면 편집 탭은 화면용 컴포넌트, 보드 탭은 보드 전용 요소(메모·텍스트·이미지·연결선)
  를 보여주며, 속성창은 화면 편집 중에만 표시
- **컴포넌트 전용 편집기**: 별도 디자인 화면에서 컴포넌트를 만들고, 이름·크기 수정 및 재편집
- **개발 명세**: 요소마다 동작 설명·입력 글자수/정규식 같은 제약을 정의 → 속성 패널에서 편집,
  캔버스 배지로 표시, HTML 내보내기에 `data-spec-*`로 포함, 화면 단위 **명세서(표)** 내보내기
- **기본 컴포넌트**: 컨테이너/행/열, 텍스트, 버튼, 입력, 체크박스, **라디오 그룹**,
  **날짜 선택(캘린더)**, **그리드(표)**, **모달/메시지박스**, 이미지, 아이콘, 구분선, **설명(주석)**
- **모바일 컴포넌트**: 토글/스위치, 토스트/스낵바, 배지, 아바타, 칩/태그, 플로팅 버튼(FAB),
  검색바, 슬라이더, 진행바, 스테퍼, 별점, 하단 탭바
- **그리드**: 열/행 추가·삭제, 헤더 **열 병합(span)**, 열 정의를 표 또는 **JSON**으로 편집
- **입력 속성**: 필수값(required) · 읽기전용(readonly) 등
- **PC / 모바일** 화면 전환 (프레임별 디바이스)
- **드래그&드롭 배치**, 이동/리사이즈, 마키(영역) 다중 선택
- **컨테이너 중첩 편집**: 컨테이너 안으로 드롭/이동하면 자식으로 들어감(상대 좌표)
- **정렬**: 좌/가운데/우 · 상/중앙/하 정렬, 가로/세로 균등 분배
- **복사 / 붙여넣기 / 복제 / 삭제** (Ctrl+C / V / D / Del, Ctrl+S 저장)
- **실행취소 / 다시실행** (Ctrl+Z / Ctrl+Shift+Z)
- **노코드 커스텀 컴포넌트**: 선택 요소를 묶어 "내 컴포넌트"로 저장. 캔버스에 놓으면
  정의와 **연결된 인스턴스**로 표시되고, 필요하면 "분리"로 개별 요소로 펼침
- **템플릿(자주 쓰는 화면 디자인)** 저장 및 현재 화면에 적용
- **HTML 내보내기**: 화면을 단독 실행 가능한 `.html` 파일로 추출
- **하단 설계 메모 패널** (접기/펼치기)
- **프로젝트 / 폴더 / 화면 파일 탐색기**
- **사용자 인증**(회원가입/로그인) 및 프로젝트 소유권
- **실시간 협업**: 같은 화면을 여는 사용자끼리 편집 내용 실시간 동기화 + 접속자 표시
- **한국어 / 영어** UI 전환

## 구조 (npm workspaces 모노레포)

```
packages/
  shared/   # 공용 타입 · Zod 스키마 · 프리미티브 레지스트리 · API 계약
  server/   # Fastify REST API + 스토리지 어댑터(로컬/Knex) + 마이그레이션
  client/   # React + Vite + Zustand 편집기
```

## 개발 실행

```bash
npm install
npm run dev          # 서버(:4000) + 클라이언트(:5173) 동시 실행
```

클라이언트는 `/api`를 서버로 프록시합니다. 브라우저에서 http://localhost:5173 접속.

개별 실행:

```bash
npm run dev:server   # API 서버만
npm run dev:client   # 클라이언트만
```

## 빌드 / 타입체크 / 테스트

```bash
npm run build        # 모든 패키지 빌드
npm run typecheck    # 전체 타입체크
npm run test         # 서버 스모크 테스트(스토리지+REST 전 과정)
```

## 저장 방식 설정

`packages/server/.env`(또는 환경변수)의 `STORAGE_DRIVER`로 선택합니다
(`packages/server/.env.example` 참고).

| STORAGE_DRIVER | 설명 | 필요 설정 |
| --- | --- | --- |
| `local` (기본) | 서버 로컬 JSON 파일 저장 | `DATA_DIR` (기본 `./data`) |
| `postgres` | PostgreSQL | `PG_HOST/PG_PORT/PG_USER/PG_PASSWORD/PG_DATABASE` |
| `oracle` | Oracle | `ORACLE_USER/ORACLE_PASSWORD/ORACLE_CONNECT_STRING` |

로컬 모드의 파일 레이아웃은 앱의 파일 탐색기와 동일하게 구성됩니다:

```
data/
  projects.json
  <projectId>/
    tree.json            # 폴더/화면 트리
    components.json      # 커스텀 컴포넌트
    templates.json       # 화면 템플릿
    screens/<id>.json    # 화면 디자인
```

### DB 마이그레이션

```bash
# PostgreSQL
STORAGE_DRIVER=postgres npm run migrate
# Oracle (oracledb 드라이버 + Instant Client 필요)
STORAGE_DRIVER=oracle npm run migrate
```

> 서버 기동 시(`postgres`/`oracle`)에도 마이그레이션이 자동 적용됩니다.

## 인증 / 실시간 협업

- 첫 화면에서 **회원가입/로그인**합니다. 비밀번호는 scrypt로 해싱되고, 인증은 HMAC 기반
  토큰(JWT 형식)으로 처리됩니다. 토큰 서명 키는 `AUTH_SECRET` 환경변수로 설정하세요
  (운영 환경에서는 반드시 변경).
- 서버 첫 기동 시 **기본 관리자 계정**이 자동 생성됩니다 — 기본값 `admin@admin.com` / `admin1234`
  (`ADMIN_EMAIL` / `ADMIN_PASSWORD` 환경변수로 변경 가능). 별도 회원가입 없이 바로 로그인할 수
  있으며, 운영 환경에서는 반드시 비밀번호를 변경하세요.
- 프로젝트는 **소유자(사용자)** 단위로 분리되어, 로그인한 사용자의 프로젝트만 보입니다.
- 같은 화면을 연 사용자끼리는 **WebSocket(`/api/ws`)** 으로 편집 트리가 실시간 동기화되며
  (라스트-라이트-윈), 상단에 접속자 아바타가 표시됩니다.
